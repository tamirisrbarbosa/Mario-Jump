
** Jogo do Mario - Simples e Divertido **

Prepare-se para pular! Você controla o Mario em sua jornada para evitar os canos.
O jogo foi criado utilizando HTML, CSS e JavaScript.

**Funcionalidades:**

* **Fundo Animado:** As nuvens se movem, criando um cenário dinâmico e envolvente.
* **Mario Saltando:** Pressione qualquer tecla para fazer o Mario pular e superar os obstáculos.
* **Cano Obstáculo:** Evite colidir com o cano para não perder o jogo.
* **Feedback Visual:** Ao colidir com o cano, a imagem do Mario muda, indicando o fim do jogo.

**Como Jogar:**

1. Acesse o link ou baixe o repositório completo em seu aparelho.
  (Link do jogo: https://mario-jump-amber.vercel.app/)
2. Caso baixe o repositório completo, abra o arquivo 'index.html' em seu navegador.
3. Pressione qualquer tecla para começar a jogar! Pule para evitar o cano.


Sinta-se à vontade para contribuir com este projeto! Se você tiver ideias ou quiser ajudar a desenvolver as funcionalidades mencionadas acima, faça um fork do repositório e crie um pull request.
